## 🧭 Quick Start — Run a Lesson

1. Clone the repository (if you haven't already):

```bash
git clone https://github.com/Anubhav2321/Python-.git
cd Python-Tutorial
```

2. Open a lesson and run it with Python 3:

```bash
python 01_Introduction/hello_world.py
```

> Tip: Use a virtual environment for larger projects:
>
> ```bash
> python -m venv venv
> source venv/bin/activate  # macOS / Linux
> venv\Scripts\activate   # Windows
> ```

## ✨ Sample Mini Projects (What you'll find in `mini_projects/`)

* **atm.py** — simple ATM simulator (PIN check, balance, withdraw, deposit)
* **quiz_app.py** — multiple choice quiz with score tracking
* **coffee_shop.py** — order system that totals prices and handles input
* **snake_game_starter/** — skeleton for creating a snake game with Pygame

Each project contains comments and instructions on how to extend it.

## 📚 Learning Path (Suggested Order)

1. `01_Introduction` — welcome & basic I/O
2. `02_Variables_and_DataTypes` — numbers, strings, booleans
3. `03_Strings` & `04_Lists` — text and collections
4. `07_Conditions` & `08_Loops` — branching and repetition
5. `09_Functions` & `10_Modules` — structure your code
6. `11_File_Handling` & `12_OOPS` — real-world programs
7. `mini_projects` — apply what you learned
